悬浮便签 · 本地验证页

本页直接以脚本方式加载 content.js（无扩展环境时自动回退 localStorage），用来在没有装扩展的情况下验证便签的交互。

验证清单：

  1. 右下角出现便签面板（未记录时显示空态）
  2. 输入框输入文字 → Enter 添加；Shift+Enter 换行
  3. 拖动顶部标题栏 → 面板移动；松手贴到屏幕边缘时会自动吸边
  4. 点 ▾ 收起成小胶囊；胶囊本身也能拖，拖完位置被记住
  5. 点面板外任意处 / 按 Esc → 自动收起成胶囊；点 📌 钉住后不再自动收起
  6. 输入到一半去勾选/删除别的条目 → 草稿不丢、光标还在
  7. 每条可勾选完成 / 复制 / 编辑 / 删除
  8. 「复制全部」生成给 AI 的清单（含站点与页面路径）
  9. 刷新页面 → 记录与位置仍在

提示：在被测应用里使用时，便签内的键盘事件不会冒泡到页面，不会误触应用快捷键。
